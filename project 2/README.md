## Проведение AA и AB-тестов

### Источник
Karpov Courses, курс "Симулятор Аналитика", https://karpov.courses/simulator

Данные с 02.05.2026 до текущего дня (обновляются в режиме реального времени). В анализе использованы данные до 07.09.2026. Данные предоставлены в рамках курса, хранятся в Clickhouse.

### Структура данных
Провожу работу с данными стартапа приложения с лентой новостей (feed_actions) и мессенджером (message_actions). 

Таблица feed_actions- информация о действиях пользователей в приложении ленты новостей:
- user_id - идентификационный номер пользователя
- post_id - номер поста
- action - вид действия пользователя в ленте (категориальная переменная). Значения - like и view.
- time - дата и время действия пользователя в ленте новостей
- gender - пол пользователя
- age - возраст пользователя
- country - страна проживания пользователя
- city - город проживания пользователя
- os - операционная система устройства, с которого заходят в приложение
- source - канал привлечение клиентов: ads (через рекламу), organic (самостоятельно)
- exp_group - группа пользователя для проведения эксперимента
### Инструменты
Jupiter Notebook, Clickhouse, seaborn, scipy
### Условие задания 
**A/A-тестирование:** проверка системы сплитования. В случае верного разделения статистически значимые различия между двумя группами встречаются только в результате случайного ложного срабатывания (в 5% случаев). Проводим симуляцию.
- Данные А/А-теста из следующего диапазона: с '2026-05-22' по '2026-05-28'
- Из групп 2 и 3 берём подвыборки без возвращения размером в 500 юзеров
- Сравниваем их t-тестом и сохраняем p-value (equal_var=False)
- Повторяем это 10000 раз

2 и 3 - две экспериментальные группы

**A/B-тестирование:**
Проводится тестирование нового алгоритма рекомендации постов. Для эксперимента задействованы группы 1 и 2 (exp_group). В группе 2 был использован один из новых алгоритмов рекомендации постов, группа 1 использовалась в качестве контрольной. Эксперимент проходил с 2026-05-29 по 2026-06-04 включительно.

Гипотеза: новый алгоритм во 2-й группе приведет к увеличению CTR (click-through rate).

### Цель исследования
Проанализировать результаты эксперимента

### A/A-тестирование
Доля p-value ниже порога значимости составляет около 0.048 (~5%). Система сплитования работает корректно.
### A/B-тестирование
Применено 5 методов анализа результатов теста: 
- t-тест
- Пуассоновский бутстреп
- тест Манна-Уитни
- t-тест на сглаженном ctr (коэффициент сглаживания α=5)
- t-тест и тест Манна-Уитни поверх бакетного преобразования

Сравниваю результаты всех тестов. Распределения для каждого случая визуализированы с помощью гистограммы.

### Вывод о результатах эксперимента
- Есть пользователи, на активность которых новый алгоритм рекомендаций повлиял скорее положительно, но есть пользователи, на которых он воздействовал скорее отрицательно.
- Общегрупповой CTR стал ниже (результат пуассоновского бутстрепа)
- Общий вывод: выкатывать алгоритм на всех пользователей не рекомендуется.
