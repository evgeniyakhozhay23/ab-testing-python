# project-ab-testing

# Проект "Тестирование механизма оплаты на сайте"

**Условие кейса и данные:** Karpov Courses, курс "Аналитика данных" (https://karpov.courses/analytics), модуль "Финальные проекты"

**Задание:** Проводится A/B тестирование нового механизма оплаты услуг на сайте. Целевой группе была предложена новая механика, у контрольной группы оставалась базовая механика. Необходимо проанализировать итоги эксперимента и сделать вывод, стоит ли запускать новую механику оплаты на всех пользователей.

**Используемые данные**
- groups.csv – файл с информацией о принадлежности пользователя к контрольной или экспериментальной группе (А – контроль, B – целевая группа)
- groups_add.csv – дополнительный файл с пользователями, который вам прислали спустя 2 дня после передачи данных
- active_studs.csv – файл с информацией о пользователях, которые зашли на платформу в дни проведения эксперимента
- checks.csv – файл с информацией об оплатах пользователей в дни проведения эксперимента

**Цель исследования:** сделать вывод, стоит ли запускать новую механику оплаты на всех пользователей.

**Шаги проведения эксперимента:**

**1. Предварительная подготовка данных**
- Провела предварительный анализ данных
- Создала бинарные переменные *is_active* и *is_purchased*. is_active фиксирует, был ли пользователь активен в дни проведения эксперимента. is_purchased фиксирует, совершал ли пользователь покупку в дни эксперимента.
- Проверила данные на баги и удалила строки с ошибками: 1) пользователи не были активны в дни эксперимента, но есть данные об их покупках; 2) проверка на дубликаты; 3) проверка на уникальность id пользователей

**2. Расчет метрик отдельно по 2 группам**
- Метрики: общее количество пользователей, количество активных пользователей, количество платящих пользователей, общая выручка, средний чек на заплатившего пользователя (ARPPU), средняя выручка от активного пользователя (ARPAU), конверсия в покупающего пользователя, доля активных пользователей из общего количества пользователей.

**3. Проведение статистических тестов**
Провела 3 статистических теста на выявление статистически значимых различий между контрольной и экспериментальной группами по 3 метрикам.
1. **Тест Колмогорова-Смирнова** (для двух независимых выборок, распределенных ненормально). Сравнение сумм, которые тратят на покупку услуг платящие клиенты по группам (изменился ли уровень трат на покупку из-за введения нового механизма оплаты).
2. **Тест хи-квадрат**. Проверяю, есть ли статистически значимая взаимосвязь между группой, к которой принадлежит пользователь, и фактом того, совершил он покупку или нет.
3. **Тест Колмогорова-Смирнова** для сравнения выручки от всех активных клиентов.

Для 1 и 3 тестов была проведена предварительная проверка на **нормальность** тестом Д'Агостино-Пирсона и на **равенство дисперсий** тестом Левена.

**4. Вывод о необходимости распространить изменения на всех пользователей**

**5. Создание функций для автоматического изменения файла и пересчета метрик**
- Функция для дополнения файла groups_add.csv новыми пользователями и пересчета метрик, рассчитанных на шаге 2
- Функция для построения визуализаций метрик
